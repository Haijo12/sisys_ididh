# Phosphor Icons

A flexible icon family with 1,512+ icons in 6 weights.

## Overview

| Property | Value |
|----------|-------|
| **Total Icons** | 1,512 |
| **Format** | PNG (24x24, white on transparent) |
| **Original Format** | SVG |
| **License** | MIT |
| **Author** | Phosphor Icons Team |
| **GitHub** | [phosphor-icons/core](https://github.com/phosphor-icons/core) |
| **Website** | [phosphoricons.com](https://phosphoricons.com) |

## Features

- **6 weight variants**: Thin, Light, Regular, Bold, Fill, Duotone
- Consistent 24x24 pixel grid
- Beautiful, modern design
- Extensive icon library
- Regularly updated
- MIT licensed

## Weight Variants

Phosphor offers 6 different visual weights:

| Weight | Stroke Width | Use Case |
|--------|-------------|----------|
| **Thin** | 1px | Delicate, minimal interfaces |
| **Light** | 1.5px | Clean, airy designs |
| **Regular** | 2px | Default, balanced look |
| **Bold** | 2.5px | Strong, emphasis |
| **Fill** | Solid | Buttons, highlights |
| **Duotone** | 2px + fill | Two-tone illustrations |
