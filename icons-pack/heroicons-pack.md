# Heroicons

A set of 648 hand-crafted SVG icons by the makers of Tailwind CSS.

## Overview

| Property | Value |
|----------|-------|
| **Total Icons** | 648 |
| **Format** | PNG (48x48, white on transparent) |
| **Original Format** | SVG (Outline + Solid variants) |
| **License** | MIT |
| **Author** | Refactoring UI / Tailwind Labs |
| **GitHub** | [tailwindlabs/heroicons](https://github.com/tailwindlabs/heroicons) |
| **Website** | [heroicons.com](https://heroicons.com) |

## Features

- Hand-crafted by professional designers
- Consistent 48x48 pixel grid
- Optimized for web interfaces
- Clean, modern aesthetic
- Used in production by thousands of apps

## Icon Categories

| Category | Examples |
|----------|----------|
| **Navigation** | arrow-* (up, down, left, right), chevron-*, home, menu |
| **Actions** | check, x, plus, minus, trash, pencil, eye |
| **Objects** | bolt, star, heart, fire, globe, flag, bookmark |
| **Interface** | cog, user, bell, magnifying-glass, envelope, phone |
| **Files** | document, folder, cloud, arrow-up-tray, arrow-down-tray |
| **Media** | play, pause, stop, speaker, video-camera, musical-note |
| **Communication** | chat-bubble, megaphone, at-symbol, link, share |
| **Status** | check-circle, exclamation-triangle, information-circle, question-mark-circle |

## Design Philosophy

Heroicons are designed to be:
- **Simple** - Easy to understand at a glance
- **Consistent** - Uniform stroke weight and sizing
- **Scalable** - Work at any size
- **Accessible** - Clear contrast and recognizable shapes
