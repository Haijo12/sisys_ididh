## Naming Convention

Icons follow the standard Lucide naming pattern:

- **kebab-case**: `arrow-down.png`, `bell-check.png`
- **Prefix groups**: `arrow-*`, `circle-*`, `square-*`, `chart-*`, `book-*`
- **Variants**: `-off`, `-plus`, `-minus`, `-check`, `-x`

## Usage
